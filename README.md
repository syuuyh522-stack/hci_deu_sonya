# hci_deu_sonya

## 오늘옷 (가칭) · 날씨 기반 옷 추천 서비스

매일 내가 정한 시간에, 우리 동네 날씨와 내 취향에 맞는 쇼핑몰 옷을 골라 알려주는 서비스입니다.

| 파일 | 내용 |
|---|---|
| [`brief.md`](brief.md) | 서비스 기획 brief (문제 정의, 퍼소나, 핵심 기능, 성공 기준, 가설) |
| [`index.html`](index.html) | 랜딩 페이지 (베타 테스터 모집용, 단일 HTML 파일) |

랜딩 페이지는 `index.html`을 브라우저로 열면 바로 볼 수 있습니다. 신청 폼은 아직 실제로 전송하지 않고 안내 문구만 보여줍니다.
